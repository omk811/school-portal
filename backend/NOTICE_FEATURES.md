# تفعيل النشر المجدول للمحبرة
المزايا المتوافقة مع الخادم السابق: تعديل الملاحظات، تثبيت المنشور حتى موعد محدد، تقويم المهام، وطباعة الجداول. 
النشر المجدول يتطلب نسخة الخادم الجديدة لكي لا يظهر المنشور في البيانات العامة قبل موعده.
1. افتح مشروع Apps Script المرتبط بجدول المحبرة الحالي، وليس مشروع سعد.
2. احفظ نسخة من الكود الحالي، ثم استبدل محتواه بملف [Code.gs](./Code.gs) المحدّث.
3. احفظ، ثم Deploy > Manage deployments > Edit، واختر New version ثم Deploy مع الاحتفاظ بنفس رابط تطبيق الويب وإعدادات الوصول الحالية.
4. لا تشغّل setupSecurity مجددًا، ولا تغيّر كلمة المرور أو جدول البيانات؛ لا توجد حاجة لتغيير الأعمدة أو تفعيل مشغلات زمنية.
5. حدّث لوحة المعلم؛ عند استجابة الخادم بالميزة noticeFeatures: 2 يصبح حقل النشر المجدول متاحًا.
يكون المنشور غير متاح للقراءة العامة والتعليق والتفاعل حتى الموعد المحدد بتوقيت عُمان.
