# تفعيل حماية لوحة المعلم

تعديل صفحات GitHub وحده لا يكفي؛ يجب نشر كود Apps Script الجديد حتى تصبح حماية الخادم فعالة.

1. افتح مشروع Apps Script المرتبط بجدول بيانات «المحبرة».
2. استبدل كود الخادم بمحتوى [Code.gs](./Code.gs)، ثم احفظ المشروع.
3. شغّل الدالة `setupSecurity` مرة واحدة من محرر Apps Script، ووافق على الصلاحيات المطلوبة.
4. من سجل التنفيذ الخاص بك، انسخ كلمة المرور المؤقتة. لا تشاركها أو تضعها في ملف عام.
5. افتح **Deploy > Manage deployments**، ثم عدّل نشر تطبيق الويب الحالي واختر **New version**. أبقِ التنفيذ باسم مالك المشروع، وإتاحة الوصول **Anyone** حتى تبقى صفحة أولياء الأمور عامة؛ عمليات المعلم وحدها تتطلب جلسة موثقة من الخادم.
6. سجّل الدخول إلى لوحة المعلم بكلمة المرور المؤقتة، ثم غيّرها من إعدادات اللوحة إلى عبارة مرور طويلة وفريدة (14 محرفًا أو أكثر).

`setupSecurity` يحفظ كلمة المرور مجزأة في Script Properties، وينشئ مفتاح توقيع للجلسات، ويحذف صف كلمة المرور القديم من ورقة الإعدادات. صلاحية جلسة المعلم ست ساعات، وتغيير كلمة المرور يلغي الجلسات السابقة.

الواجهة الأمامية الجديدة تستعمل إجراءات منفصلة: قراءة عامة للملاحظات وتعليقاتها، وإضافة تعليق أو تفاعل ضمن صلاحيات محدودة، وعمليات المعلم بعد المصادقة. لا تُعدّل إعداد مشاركة جدول البيانات إلى عام؛ يجب أن يبقى الجدول خاصًا، وأن يكون الوصول إليه عبر Apps Script فقط.
